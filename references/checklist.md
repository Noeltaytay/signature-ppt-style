# Checklist

## A. Visual system

- [ ] Palette is chosen from the content; one accent hue; 4.5:1 text contrast.
- [ ] Structure and decoration match the signature system; only colors changed.
- [ ] Content pages use the chosen background, not pure white/near-black.
- [ ] Header 72 px and footer 40 px use the primary/dark field.
- [ ] Title 44 px, subtitle 24 px, body ≥ 20 px, caption ≥ 16 px.
- [ ] Accent is small-area only.
- [ ] No card grid; content uses rows, columns, bands, or one large field.
- [ ] No tech grids, dotted rings, icon walls, or decorative English on content
      pages.
- [ ] Cover/TOC keep the fixed field composition.
- [ ] Closing uses the primary field and one claim.

## B. Chapter dividers

- [ ] Every chapter has a divider.
- [ ] Giant chapter number is inside the canvas.
- [ ] Light plate text fits inside the plate.
- [ ] English subtitle fits inside the plate.
- [ ] Tagline fits before the right panel.
- [ ] Right panel uses a **schematic**, not a real photo/screenshot.
- [ ] `PART 0X` and page number are correct.
- [ ] TOC markers point to divider pages.

## C. Content pages

- [ ] One claim per page.
- [ ] ≤ 7 content units.
- [ ] Title states the conclusion, not just the topic.
- [ ] No text overlap, clipping, or orphaned lines.
- [ ] Images use `meet` for transparent cutouts; no cut-off subject.
- [ ] Source/boundary line in the footer where needed.
- [ ] Page number in header and footer matches.

## D. Evidence

- [ ] Every metric is supplied by the user.
- [ ] Role language is precise (负责/参与/探索).
- [ ] Research separates completed vs exploring.
- [ ] No fake project photos or network images.
- [ ] Job samples have company, role, source, and date.
- [ ] Awards use exact names/levels.

## E. Files

- [ ] One SVG per page, sequential filenames.
- [ ] One note per page, stems match SVGs.
- [ ] `notes/total.md` covers every page.
- [ ] `animations.json` keys match SVGs.
- [ ] All image hrefs resolve.
- [ ] `design_spec.md` and `spec_lock.md` match page count.
- [ ] Backups exist for structural changes.

## F. Export

- [ ] SVG quality: 0 blocking errors.
- [ ] Animation config valid.
- [ ] `check_style.py` has no errors.
- [ ] Transitions are Fade; no fly/bounce/spin/zoom.
- [ ] Divider animation is number → schematic → plate → tagline.
- [ ] Content animation is title → evidence click → result.
- [ ] PPTX page count = notes count = roster count.
- [ ] PPTX postflight passed or passed-with-warnings.
- [ ] PDF page count matches.
- [ ] Preview/overview full-bleed, no white margins.
- [ ] Latest files reported with exact paths.

## G. Privacy

- [ ] No phone, email, ID, or address.
- [ ] No personal data in public templates.
- [ ] No confidential project photos in a public repo.
- [ ] Public skill uses placeholders only.
