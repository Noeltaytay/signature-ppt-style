# Product Launch — Same Style, Different Topic

An 11-page product launch using the blue-gray system with a darker tech lean.

## Roster

| Page | Layout | Content |
| ---: | --- | --- |
| 01 | Cover | Product name, one-line promise, hero image |
| 02 | Agenda | Problem / product / proof / launch |
| 03 | Divider 01 | The problem |
| 04 | Statement | The user pain in one sentence |
| 05 | Divider 02 | The product |
| 06 | Three-column | Three capabilities |
| 07 | Process | How it works (4 steps) |
| 08 | Proof | Benchmark / customer quote / demo still |
| 09 | Divider 03 | Launch |
| 10 | Pricing / CTA | Offer + next step |
| 11 | Closing | One-line vision |

## Style notes

- Use `dark-tech` preset if the product is AI/robotics; keep the same chapter
  divider system and light/dark alternation.
- Real product screenshots only; no fake UI.
- Hero image licensed or owned.
- Divider schematics: pain map, capability stack, launch steps.

## Time

11 pages / 8 minutes. Demo/proof gets 2–3 minutes.
