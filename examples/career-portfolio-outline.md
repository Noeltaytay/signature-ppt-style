# Career Portfolio — Same Style, Original Use Case

A 15-page career-planning competition deck. This is the original use case for
the style, not its only use.

## Roster

| Page | Role |
| ---: | --- |
| 01 | Cover: identity + target role |
| 02 | Contents: five sections + page markers |
| 03 | Divider 01: 职业认知 |
| 04 | Four real job samples + common capability band |
| 05 | Divider 02: 岗位匹配 |
| 06 | Five-row capability matrix + GPA band |
| 07 | Divider 03: 项目证据 |
| 08 | Core project: real photos/screenshots + chain |
| 09 | Secondary project: system diagram + points |
| 10 | Divider 04: 科研与实习 |
| 11 | Research + competition |
| 12 | Internship |
| 13 | Divider 05: 职业规划 |
| 14 | Three-stage plan |
| 15 | Closing |

## TOC markers

03 / 05 / 07 / 10 / 13.

## Style notes

- Divider panels: robot structure, checklist, project chain, point-cloud field,
  three-stage steps.
- Real photos only on cover, content pages, closing.
- No invented success rate/accuracy/latency.
- No phone/email/address.
- 6 minutes: dividers 3–5 s; core project 75 s.

## Time budget

~350 s: opening/dividers 50, career+fit 70, projects 120, research+intern 75,
plan+closing 35.
