# Academic Defense — Same Style, Different Topic

A 12-page thesis defense using the blue-gray editorial system.

## Roster

| Page | Layout | Content |
| ---: | --- | --- |
| 01 | Cover | Title, candidate, supervisor, institution |
| 02 | Agenda | Background / method / results / discussion |
| 03 | Divider 01 | Background |
| 04 | Context | Problem, gap, objective |
| 05 | Question | Research questions / hypotheses |
| 06 | Divider 02 | Method |
| 07 | Process | Data → method → validation |
| 08 | Results | One key chart + one table |
| 09 | Divider 03 | Discussion |
| 10 | Comparison | Findings vs prior work |
| 11 | Statement | Contribution + limitation |
| 12 | Closing | Conclusion + thanks |

## Style notes

- Warm-academic variant may replace gold with burgundy, but keep the same
  structure and type scale.
- Divider schematics: research gap map, method chain, contribution diagram.
- Do not invent IoU/F1/accuracy; use only measured results.
- Separate completed, in-progress, and future work.

## Time

12 pages / 15–20 minutes. Dividers 5 s; method/results 2–3 minutes each.
