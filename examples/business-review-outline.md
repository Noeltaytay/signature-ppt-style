# Business Review — Same Style, Different Topic

A 12-page quarterly review using the blue-gray editorial system.

## Roster

| Page | Layout | Content |
| ---: | --- | --- |
| 01 | Cover | Quarter, business unit, one headline |
| 02 | Agenda | 3 sections: performance, issues, next steps |
| 03 | Divider 01 | Performance |
| 04 | KPI band | 3–4 numbers with context |
| 05 | Trend | One chart + one insight |
| 06 | Divider 02 | Issues |
| 07 | Two-column | Issue / root cause |
| 08 | Process | Fix actions + owner + timing |
| 09 | Divider 03 | Next steps |
| 10 | Timeline | Next quarter roadmap |
| 11 | Statement | The ask / decision needed |
| 12 | Closing | One-line commitment |

## Style notes

- Cover/TOC/divider fields navy; content pages light.
- Divider schematics: KPI grid, issue tree, roadmap steps.
- One chart per data page; no 3D, no exploded pie.
- KPI numbers must be real; if not available, use placeholders and mark them.
- Gold only for the key number/rule.

## Time

12 pages / 10 minutes. Dividers 3–5 s each; data pages 60–90 s.
